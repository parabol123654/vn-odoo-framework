# Odoo 16 CE itself is installed separately; see the upstream install guide.
#
# vn_core and l10n_vn_vas_reports currently need no Python package beyond what
# Odoo 16 already requires. The Domain layer deliberately depends on nothing
# outside the standard library.
#
# OCA dependencies are Odoo *addons*, not pip packages. Either clone the repos
# into addons_path (see scripts/odoo.conf.example):
#
#   OCA/reporting-engine            report_xlsx, report_xlsx_helper
#   OCA/queue                       queue_job
#   OCA/account-financial-tools     account_asset_management  (fixed assets —
#                                   account_asset is Enterprise-only in 16)
#
# ...or install them from PyPI, which puts them on addons_path automatically:
#
#   odoo-addon-report-xlsx>=16.0dev,<16.1dev
#   odoo-addon-queue-job>=16.0dev,<16.1dev
#   odoo-addon-account-asset-management>=16.0dev,<16.1dev
#
# All of them must come from the 16.0 branch. An addon from another series
# installs and then fails on a field that moved.

# Excel export. Deliberately not pinned here: whatever Odoo 16 installs is what
# runs, and Odoo 16 pins XlsxWriter==1.1.2 — a 2018 release.
#
# Treat 1.1.2 as the baseline. Any newer method must be feature-detected, which
# scripts/check_repo.py enforces: this is the version that once shipped a
# working export from a developer machine and raised on the customer's.
# Nothing is added to the server's dependencies by this framework.
XlsxWriter>=1.1.2
